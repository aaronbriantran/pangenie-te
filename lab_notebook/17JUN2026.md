I test running Snakemake using the FastQC pipeline. I need to validate:
* that the Snakemake is correct, compiles, and runs
* that I'm able to run Snakemake from the command line correctly
* that it splits up jobs correctly
* that it can handle symlinks

I run Snakemake with:

<code>conda activate snakemake</code>
<code>snakemake --profile myprofile --jobs 3 --report --report-after-run --use-conda</code>

To run this, a few modifications to the conda environment that runs snakemake are required:
<code>conda install -c conda-forge "conda>=24.7.1"</code>
This line installs a more recent version of the conda executable within the conda environment (!) for conda environments to be created by rules. These environments are stored in .Snakemake, in the working directory.
<code>conda install -c bioconda snakemake-executor-plugin-slurm</code>
This line installs the snakemake-executor plugin, which lets Slurm interact with Snakemake. Without this, the --executor flag passed by the config file won't be recognized.

I should also note that:
* the caching of steps when steps are rerun is real, and we don't need to modify anything to make that happen!
