# Pangenie TE Analysis

This repository includes code related to work for identifying eQTLs in an ASE analysis of polymorphic TEs, taken from a family duo of iPSCs as described in Quaid et al. (2025).

In this analysis, we:

1. impute all variants, including structural variants, via PanGenie and the human pangenome (HPRCv1.1)
2. annotate variants via RepeatMasker
3. annotate transposable elements via L1ME-AID, as described by the HGSVC in Logsdon et al. (2025).
4. phase all variants via SHAPEIT, using statistical phasing and lineage phasing
5. validate identified TEs with overlaps against consensus TE positions and lengths in HPRCv2
6. validate TE genotyping and phasing by constructing a phased diploid graph and genotyping from it using the vgtools toolkit.

Below, each step of the analysis, relevant code, and reasoning behind the decisions are described.

Then, I discuss general intuitions and findings generated by this process, and how that might apply in the future.

Finally, I provide some context and consider future applications of this line of work.
