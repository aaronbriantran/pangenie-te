## Modifying Xiaoyu's .bed file

Start by taking the L1ME-AID annotations raw from Xiaoyu and grepping out the insertions and deletions. Extend the second coordinate by the length of the TE identified in the fifth column to create insertions with their true length as a feature.

```bash
awk 'BEGIN{FS=OFS="\t"} {$3=$2+$5; print}' ins.bed > ins_extended.bed
```


## Intact TEs that are in unphased F1 callset

Cat the extended insertions and deletions together. Use a 95% reciprocal overlaps cutoff with bedtools.

For the unphased F1 genotyping results:

```bash
bcftools view /scratch/atran/final/3_pangenie/vcfs/F1_genotyping_biallelic.vcf | bedtools intersect -a stdin -b inputs/limeaid_lengthfixed.bed -f 0.95 -r -wo > results/te_match/any_unphased_repeat_intersect.txt
```

Yielding **2442 TE candidates**.

## Intact TEs that are in the phased F1 callset and validate by vg call breakpoint analysis

We can modify the above commands to yield VCF bodies for all three by using the -wa flag to write in terms of the VCF. Something of the form:

```bash
bcftools view /scratch/atran/final/3_pangenie/vcfs/F1_genotyping_biallelic.vcf | bedtools intersect -a stdin -b inputs/limeaid_lengthfixed.bed -f 0.95 -r -wa -header > results/te_match/F1_unphased_repeat.vcf
```

Which we can then intersect with the vg callset. We can see what was both phaseable and breakpoint validated in F1. After a little compressing and indexing:

```bash
bcftools isec -p results/te_match/phased_bp -w1 -n~11 results/te_match/F1_phased_repeat.vcf.gz results/pack_and_call/F1/F1_create_diploid_graphs.vcf.gz
```

**Yielding results/te_match/phased_bp.0000.vcf, with 56 records.**

```bash
bcftools view -i '(GT="1|0") || (GT="1|0")' 0000.vcf > F1_phased_bp_het.vcf
```
