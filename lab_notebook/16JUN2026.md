I create a basic Snakemake workflow for phasing.
* combine VCFs and convert to a BCF for all samples
* split the BCF into a bunch of chunks
* phase_common each chunk
* ligate chunks by chromosome
* cat chromosomes together

I avoid phase_rare because in the phase_rare documentation they "recommend to use phase_rare for datasets with a sample size greater than 2,000 samples. For smaller smaple sizes, phase_common could do the job." (CITE: https://odelaneau.github.io/shapeit/docs/documentation/phase_rare/).

I'll need some extra files as inputs. The McCoy and Werling labs have made most of it available at https://github.com/JosephLalli/phasing_T2T.
* use the biallelic 2504 sample bcf with index for a reference panel (from 1KG: https://s3-us-west-2.amazonaws.com/human-pangenomics/index.html?prefix=T2T/CHM13/assemblies/variants/1000_Genomes_Project/chm13v2.0/Phased_SHAPEIT5_v1.1/)
* use the genetic maps provided there too (https://github.com/JosephLalli/phasing_T2T/tree/main/resources/recombination_maps/t2t_native_scaled_maps)
* I also generate a pedigree file simply via: <code>echo  -e 'F1\tM1\tNA' > config/family.fam</code>. The requirements for the pedigree file are given here: (CITE: <https://odelaneau.github.io/shapeit/docs/documentation/phase_common/#usage2-phasing-related-samples>)


Some things I'll need to test for:
* how many sites are excluded because they aren't in the reference panel?
* do I lose transposable elements? technically, SHAPEIT can phase indels, but I'm not sure that it can do SVs. SHAPEIT common has settings to filter only for SNPs (meaning it must do more than SNPs) (CITE: https://odelaneau.github.io/shapeit/docs/documentation/phase_common/)
* I suspect that phase_common only outputs the phased sites, so you'll need to cross reference with the original VCFs to see how many sites are not phased, their attributes, etc.
